# Autos_Price_prediction
# 🚘 AutoPrice AI

## Smart Car Price Prediction Using Machine Learning

AutoPrice AI is a Streamlit web application that predicts the estimated price of a car based on its vehicle dimensions, engine specifications, weight, and mileage information.

## ✨ Features

* 🚗 Simple and user-friendly interface
* 📏 Vehicle dimension inputs
* ⚙️ Engine specification inputs
* ⛽ City and highway mileage inputs
* 🤖 Machine Learning based price prediction
* 📊 Automobile dataset preview
* 📥 Downloadable prediction report in CSV format
* 🎨 Modern Streamlit interface

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-learn
* Pickle
* CSV Dataset

## 🚀 How to Run

### 1. Install Required Libraries

Open Command Prompt or PowerShell in the project folder:

```bash
pip install streamlit pandas scikit-learn
```

If `pip` does not work:

```bash
python -m pip install streamlit pandas scikit-learn
```

### 2. Keep All Files in One Folder

```text
app.py
car_price_model.pkl
autos_dataset.csv
```

### 3. Run the Application

```bash
streamlit run app.py
```

The application will open in your web browser.

## 🧠 How It Works

1. Enter the car specifications.
2. The application prepares the input data.
3. The input features are arranged according to the trained model.
4. The Machine Learning model predicts the car price.
5. The estimated price is displayed.
6. The prediction can be downloaded as a CSV file.

## 📊 Dataset

The project uses `autos_dataset.csv` as the automobile dataset.

The application also provides a dataset preview showing sample records.

## 📥 Prediction Report

After prediction, users can download the result as:

```text
car_price_prediction.csv
```

The report contains the entered car specifications and the estimated price.

## ⚠️ Disclaimer

The predicted price is an estimated value generated by the Machine Learning model. It should not be considered a guaranteed market price.
